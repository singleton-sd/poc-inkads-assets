# Fonts (outline tooling)

Open Sauce Sans OTFs used by `pnpm outline:text` to convert lockup/wordmark
`<text>` into paths.

- License: SIL Open Font License — see `Open Sauce Sans OFL.txt`
- Source: https://github.com/marcologous/Open-Sauce-Fonts

These files are for build tooling only; they are not served on the Pages CDN.
